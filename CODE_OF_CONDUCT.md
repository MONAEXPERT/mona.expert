# Code of Conduct

## Our Pledge

We pledge to make participation in this project respectful, constructive, and focused on improving secure agent tooling.

## Expected Behavior

- Be kind and direct.
- Assume good intent while still reviewing security claims carefully.
- Keep disagreement technical and evidence-based.
- Respect privacy, confidentiality, and responsible disclosure.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language
- Publishing private information without consent
- Publicly disclosing exploitable security issues before maintainers can respond
- Using the project space to request or provide operational harm

## Enforcement

Maintainers may edit, remove, or reject comments, issues, pull requests, or participation that violates this code of conduct.
