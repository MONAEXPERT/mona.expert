## [1.0.0] — 2026-08-08

First stable release.

### Added

- Secure AI agent wrapper with injection guard, safety engine, and consent management
- Multi-tenant API key authentication
- Real-time SSE streaming for LLM responses
- Function/tool calling support with cost budgets and alerts
- Web dashboard with live activity feed, audit log, and agent management
- One-command installer (`curl … | bash`)
- Docker support with docker-compose
- Machine-bound license protection for distributed releases
- Open-core licensing: MIT for source, proprietary for packaged releases
